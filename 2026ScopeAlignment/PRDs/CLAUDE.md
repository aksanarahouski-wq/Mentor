# CLAUDE.md — PRDs (Product Requirements Documents)

## What This Is

Detailed product requirements for enhancement items that have been scoped and are ready (or near-ready) for development. Each PRD specifies exactly what needs to be built, the expected behavior, and acceptance criteria.

## Naming Convention

Files follow the same item numbering from `../SystemEnhancements.md`: `Item{##}_{Topic}_PRD.md`

## Files

| File | Item # | What It Covers |
|------|--------|---------------|
| `Item21_NationalAffiliate_PRD.md` | #21 | National Affiliate concept — granting cross-region access to orphan programs |

## Workflow

1. Item is identified in `../SystemEnhancements.md`
2. If needed, research is done in `../SupportingDocuments/`
3. Hours are estimated in `../estimates/`
4. When the item is prioritized for delivery, a PRD is written here
5. PRD is reviewed with the client, then handed off for development
