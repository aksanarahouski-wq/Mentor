Request 5: Allow for data comparison on NQMS snapshot page (***both program and affiliate levels)

Program level – ability to compare against programs in the state or programs like theirs across the country (i.e. 1:1 mentoring for grades 6-8 with academically at-risk students)

Affiliate level – ability to see how their programs are doing in relation to aggregate data nationally

Addresses: 

Data requests from programs and affiliates to see how their program or affiliate is doing in relation to others for reporting and/or grant request purposes.

Notes: 

Could this be available in the NQMS snapshot data (visually dynamic) or would it need to be in a report?

Filtering would need to be available

Would we need to create an opt-in consent for data to be available or seen at an aggregate level? We would need to think through potential implications of making this data available to others, especially if they are able to print or download it in some way. We would have to make it so that no identifying information could be available—I couldn’t use the filter function to narrow down and find a specific program in my state or region to compare my program’s data to.
